# not been validated against this codebase.

# Environment variable loading (.env)

# HTTP stack used by alpaca-py

# ---------------------------------------------------------------------------
# NOTE ON TECHNICAL INDICATORS (pandas-ta)
#
# pandas-ta is deliberately NOT listed as a dependency:
#   * It has been withdrawn from PyPI - `pip install pandas-ta` now fails with
#     "No matching distribution found" on current Python versions.
#   * The old 0.3.14b0 release imports `numpy.NaN`, which numpy 2.x removed,
#     so it would crash on import even if it were still available.
#
# strategy.py does not need it. It detects whether pandas-ta is importable and
# otherwise uses equivalent built-in pandas implementations (SMA, EMA, and a
# proper Wilder-smoothed RSI). The indicator values are the same.
#
# If you specifically want pandas-ta anyway, install it yourself alongside a
# compatible numpy, e.g.:
#     pip install "numpy<2" pandas-ta
